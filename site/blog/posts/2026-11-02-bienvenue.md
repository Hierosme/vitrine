# Bienvenue sur le blog

Ce que vous trouverez ici : des retours d'expérience sur Ansible, l'automatisation réseau, la livraison continue et la vie de freelance.

<!-- more -->

## Les sujets

- **Ansible et Python** : structurer le code en rôles et Collections, écrire les modules et lookup plugins qui manquent.
- **Network as Code** : configurer les équipements réseau depuis Git, avec relecture et déploiement automatisé.
- **CI/CD** : concevoir des pipelines de livraison continue, pour les applications comme pour l'infrastructure.
- **Sécurité** : appliquer une démarche de conformité du SI dans le code d'infrastructure.
- **Culture DevOps et freelance** : transmettre, documenter, rendre les équipes autonomes.

## Le fil rouge

Chaque article suit la même devise : *make it work, make it simple, make it manageable*. Faire fonctionner, simplifier, puis rendre maintenable par les équipes.
